About

Mirrowel's Proxy is a universal LLM Gateway that standardizes multiple providers (OpenAI, Anthropic, Gemini, etc.) into a single OpenAI-compatible endpoint. It handles key rotation, load balancing, and retries automatically.

Quick Usage

Point your OpenAI client to the proxy URL and use the format provider/model.

import openai

client = openai.OpenAI(
    api_key="sk-proxy-key",      # Your proxy key
    base_url="http://localhost:8000/v1" 
)

response = client.chat.completions.create(
    model="anthropic/claude-3-opus", # Format: provider/model
    messages=[{"role": "user", "content": "Hello world!"}]
)

print(response.choices[0].message.content)

cURL Example

curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-proxy-key" \
  -d '{
    "model": "gemini/gemini-pro",
    "messages": [{"role": "user", "content": "Explain quantum computing"}]
  }'
